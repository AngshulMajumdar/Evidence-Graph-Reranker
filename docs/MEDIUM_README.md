# Medium publishing instructions

`article.md` contains the full long-form article in standard Markdown with six image references. It uses ordinary headings, paragraphs, lists, tables, images, and a small code example; no GitHub-specific shortcode or Jekyll extension.

For Medium, paste the article text, then upload the six PNG images from `docs/images/` in the same numbered order. Medium may not import repository-relative image paths automatically. For GitHub Pages, the same article is already rendered into `docs/index.html` (openable immediately with no build step).
