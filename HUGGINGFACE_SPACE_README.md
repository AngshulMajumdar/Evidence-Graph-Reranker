# Evidence Graph Reranker

A training-free joint evidence selector, combining public neural relevance scorers with one fixed graph rule. Source and documentation: [installation](INSTALL.md), [methodology](results/methodology.md), [numerical results](README.md). The first use downloads official pretrained models from their authors' repositories.
